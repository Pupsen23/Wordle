# Wordle

Консольная реализация популярной игры Wordle на языке C# (.NET).

## 📋 О проекте

Этот проект представляет собой консольную версию игры Wordle, в которой игрок должен угадать загаданное слово за ограниченное количество попыток. Приложение поддерживает настраиваемые параметры игры, словари слов и цветовую индикацию результатов.

## ✨ Возможности

- 🎮 Интерактивный игровой процесс в консоли
- ⚙️ Настройка параметров через аргументы командной строки (длина слова, количество попыток и т.д.)
- 📚 Поддержка пользовательских словарей
- 🎨 Цветовая индикация правильных букв и позиций
- 🧪 Покрытие модульными тестами
- 📖 Встроенная справка по использованию

## 🚀 Начало работы

### Требования

- [.NET SDK](https://dotnet.microsoft.com/download) (версия 6.0 или выше)

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Pupsen23/Wordle.git
   cd Wordle
   ```

2. **Соберите проект:**
   ```bash
   dotnet build
   ```

3. **Запустите игру:**
   ```bash
   dotnet run --project Wordle.App
   ```

### Аргументы командной строки

Приложение поддерживает различные аргументы для настройки игры. Для просмотра доступных опций используйте:

```bash
dotnet run --project Wordle.App -- --help
```

Примеры использования:
```bash
# Запуск с указанием конкретного слова
dotnet run --project Wordle.App -- --word APPLE

# Запуск с пользовательским словарём
dotnet run --project Wordle.App -- --dictionary path/to/words.txt
```
